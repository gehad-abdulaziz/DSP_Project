Part 1 — DTFT (Discrete-Time Fourier Transform)

Generates a composite sinusoidal signal with Gaussian noise, computes the DTFT using manual loops, identifies frequency peaks, and verifies the result against NumPy's FFT.

Overview
Parameters
Results
Console

🎯 Objective

Compute the Discrete-Time Fourier Transform of a noisy signal from the mathematical definition (using nested loops) and demonstrate that the FFT is a sampled version of the DTFT.

📐 Algorithms

  • Signal generation: x[n] = A₁sin(2πF₁n/Fs) + A₂sin(2πF₂n/Fs) + noise
  • Manual DTFT: X(ω) = Σ x[n]·e^(-jωn) evaluated at a frequency grid
  • Peak detection: scipy.signal.find_peaks on the positive-frequency magnitude
  • FFT verification: compare manual DTFT at ω=2πk/N against np.fft.fft

📂 Inputs / Outputs

Input: Mathematically generated composite signal.
Outputs: Time-domain plot, magnitude/phase spectrum, effect-of-N comparison, peak frequencies, FFT vs DTFT error.

Part 2 — Convolution & Difference Equations

Applies moving average filters, compares time-domain and frequency-domain convolution (with and without zero-padding), and demonstrates stable vs. unstable first-order difference equations.

Overview
Parameters
Results
Console

🎯 Objective

Demonstrate linear convolution via np.convolve, the convolution theorem (DFT multiplication with zero-padding gives the same linear convolution), and the impulse response of a first-order IIR system.

📐 Algorithms

  • Moving average: h[n] = 1/M for n = 0..M-1 (FIR filter)
  • Frequency-domain convolution: y = IFFT(FFT(x,L)·FFT(h,L)), L≥N+M-1
  • Circular convolution error: without zero-padding, wrap-around corrupts M-1 samples
  • Difference equation: y[n] = a·y[n-1] + x[n]; impulse response = aⁿ

📂 Inputs / Outputs

Input: Noisy sinusoid (mathematical).
Outputs: Moving average plots, domain comparison, frequency responses, stable/unstable difference equations.

🎯 Objective

Analyze a real speech signal in both time and frequency domains, measure its spectral characteristics, and create a noisy version by injecting a known sinusoidal interference for Part 4 to remove.

📐 Algorithms

  • Hann-windowed FFT: reduces spectral leakage for magnitude spectrum
  • Spectrogram (STFT): short-time Fourier transform with Hann windows
  • Energy bandwidth: frequency below which 95% of the energy lies
  • Interference injection: A·sin(2πf₀t) where A is set by the target SNR

Overview
Parameters

🎯 Objective

Remove a known sinusoidal interference from a speech signal using a second-order IIR notch filter. Verify stability via pole locations and measure the narrow-band attenuation.

📐 Algorithms

  • Notch filter: H(z) = K·(1−2cos(ω₀)z⁻¹+z⁻²) / (1−2r·cos(ω₀)z⁻¹+r²z⁻²)
  • Pole-zero diagram: zeros on the unit circle, poles just inside (radius r)
  • Stability check: all pole magnitudes < 1
  • Band-RMS measurement: FFT magnitude in a narrow band around the notch frequency

Part 5 — 2D Fourier Transform & Image Filtering

Computes the 2D DFT of a grayscale image and applies ideal circular low-pass, high-pass, and Gaussian low-pass masks in the frequency domain.

Overview
Parameters
Results
Console

🎯 Objective

Demonstrate 2D frequency-domain image filtering: how ideal circular masks keep or remove spatial frequencies, and the ringing (Gibbs phenomenon) caused by the sharp cutoff of the ideal filter vs. the smooth Gaussian.

📐 Algorithms

  • 2D DFT: fft2 + fftshift to center the spectrum
  • Ideal LP/HP masks: binary circle of given radius in frequency space
  • Gaussian LP: exp(−d²/(2σ²)) — smooth rolloff avoids ringing
  • Inverse filtering: multiply spectrum × mask → ifftshift → ifft2

📂 Inputs / Outputs

Input: data/image.png

Overview
Parameters
Results
Console

🎯 Objective

Demonstrate frequency-domain image denoising: add known periodic noise, locate the noise peaks in the 2D spectrum, zero them out with a notch mask, and quantify the restoration quality.

📐 Algorithms

  • Periodic noise: A·sin(2π(u₀x/W + v₀y/H)) creates exactly 2 bright points in the spectrum
  • Notch mask: set a small circular region around each noise peak to zero
  • MSE: mean((original − restored)²)
  • PSNR: 10·log₁₀(255² / MSE) — higher is better

Input: data/image.png

Project Information

Multi-Domain Digital Signal Processing — Project

📖 Description

A comprehensive DSP project covering six key areas: DTFT computation, convolution and difference equations, audio analysis and filtering, and 2D image Fourier transform with denoising. Each part demonstrates fundamental concepts with real data and interactive parameter control.

🛠️ Technology Stack

  • Python — Core DSP implementations
  • NumPy / SciPy — Numerical computing and signal processing
  • Matplotlib — Scientific visualization
  • OpenCV — Image loading and grayscale conversion
  • Flask — Web application backend
  • Vanilla JS/CSS — Premium dark-themed frontend

🚀 Getting Started

  1. Install dependencies: pip install -r requirements.txt flask
  2. Place speech.wav and image.png in the data/ directory
  3. Launch the app: python app.py
  4. Open http://localhost:5000 in your browser
  5. Click "RUN ALL EXPERIMENTS" or run individual parts

🔧 CLI Usage

The original command-line pipeline still works:

python main.py          # Run all 6 parts
python main.py 3 4      # Run only parts 3 and 4
